2. What this app processes

Camera access is used so you can point at a menu, sign, label, or other readable text. You may also pick a photo from the system photo picker. Only the image you select is read. Live frames and user-selected photos stay on the device for OCR, optional on-device AI explanation, translation, and overlay display. The app is not designed to upload scene images or recognized text to NEXTBASE or a third-party AI API.

3. On-device processing

  • Apple Vision reads visible text.
  • Deterministic code parses prices when present and stores free-use fingerprints locally.
  • Apple Foundation Models may run on-device to explain the visible text. If unavailable, the app falls back to OCR and translation.
  • Apple Translation may download language resources under Apple’s control.

4. Permissions and withdrawal of consent

Camera permission can be withdrawn in iOS Settings → Menu Translator → Camera. After withdrawal, live capture stops. Photo Library add permission is used only if you tap Save. The album picker is Apple’s system picker; the app receives only the photo you choose. You can refuse the picker or later delete saved images from Photos.

5. Data stored on this iPhone

The following are stored in this app’s standard UserDefaults (not Keychain, not a NEXTBASE server):

  • Remaining free successful reads for this installation
  • Local fingerprints of scenes already counted, so the same paper is not counted again
  • Display settings (overlay size and optional translation-target override)
  • A short-lived exchange-rate cache (about one hour)

These values stay on the device until you delete the app, or until the rate cache expires. Deleting the app removes this app container, including those UserDefaults values. There is no NEXTBASE account and no server-side copy for NEXTBASE to delete on request.

6. Save and Share

If you tap Save, a composed image can be written to your Photo Library. If you tap Share, the system share sheet is presented with the image and recognized text. These actions happen only after you choose them.

7. Exchange rates and third parties

Optional FX requests to Frankfurter send currency codes only, not photos or recognized text. If FX fails, translation and understanding still work. Rates may be cached on device for about one hour. Converted overlay amounts use the iPhone currency and are approximate for that day’s rate.

NEXTBASE does not keep FX request logs. Whether Frankfurter retains request logs is outside this app. Treat that as unverified. Payments and Restore use Apple StoreKit. NEXTBASE does not receive payment-card details.

8. Free-use and Travel Pass

This installation includes 3 successful reads of new scenes. The allowance does not renew each calendar month. A use is consumed only when a new fingerprint produces a valid result. A verified StoreKit 30-Day Travel Pass (non-renewing) is checked from Apple transaction data on this device.

9. No account

No NEXTBASE login, no scene-history server, no advertising SDK in this version. NEXTBASE does not sell personal information and does not share scene photos with third parties.
