Privacy

This page describes the NowCheck product that is running now. It does not describe a future version.

One worldwide app · Updated 2026-09-24 · Operator: Norimasa Nakamura, NEXT BASE-Japan

Location

NowCheck asks for location only while the app is in use. That location biases place search and, when Cooperation is on, finds requests in a coarse area around the phone.

The place you open is stored with a place identifier. That identifier includes the place’s coordinates and name, so the same place can be matched later. The phone’s own precise location is not written as a separate GPS-history field.

CloudKit

Ask NOW and human answers use Apple iCloud CloudKit, public database, container iCloud.com.nextbase.nowcheck, production environment. Apple processes that data under Apple’s terms.

A request stores a request id, the place identifier, the place name, a coarse area cell for the place, created and expiry times, a schema version, and an open or answered status. An unanswered request stays open for 30 minutes.

An answer stores a response id, the request id, the place identifier, one structured state (not busy, normal, busy, or there is a line), created time, the time until which it counts as current (60 minutes), a schema version, and the iCloud creator record name of the person who posted it.

Human observations and the short note

An answer is a human observation, not an official status. It can be missing, old, or wrong. When nothing current exists, NowCheck shows that the now is unknown.

The short note is optional. When it is posted, NowCheck stores the original text and, when it can tell, the source language. The note is not rewritten on the server. On the viewer’s iPhone, Apple Translation may show it in the app’s language. If translation fails, the original note stays visible. The original can still be opened when a translation is shown.

Moderation, report, and block

Before a short note is posted, NowCheck rejects notes that match its prohibited-content filter, and notes longer than 80 characters. A rejected note is not saved.

On a visible observation, Report opens an email to info@nextbase-japan.com with the subject NOWCHECK report and the response id. Hide on this device only hides that creator on the phone that tapped it. It does not block them for anyone else.

A service block is a CloudKit record of type ServiceBlock naming a creator record. Clients that have this build will not show that creator’s observations, and that creator cannot ask or answer. The block is not the same control as hide-on-device.

Contact

Support and privacy: info@nextbase-japan.com. Support page: public-nowcheck-support.html.

NowCheck does not ask you to create a profile, follow people, or chat. This version does not send push or local notifications. The 30-minute and 60-minute limits change what the app shows as current. They are not a promise that Apple deletes the CloudKit record at that minute.
